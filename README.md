# Ritik Singh — Portfolio

A modern frontend portfolio built with React, Vite, GSAP, and Lenis — smooth animations, clean design, deployed on Vercel.

🔗 **Live:** [ritiksinghportfolio.vercel.app](https://ritiksinghportfolio.vercel.app/)

## Tech Stack

- React 18
- Vite
- GSAP (animations)
- Lenis (smooth scroll)
- CSS

## Features

- Smooth scroll animations powered by GSAP and Lenis
- Minimal design with strong typography — Satoshi and Barlow Condensed
- Icons via Heroicons and TechIcons
- Fully responsive, clean layout
- Deployed on Vercel

## Inspiration

Inspired by modern portfolios — Khoa Phan, CodeGrid, Sasha Satchi.

## Run Locally

```bash
npm install
npm run dev
```
